auto_explain plans & reports

Start up files come from the query string, e.g. ?file=train.sql&file=user.sql. Further parameters: min_duration, analyze, format, track, split, top, waits. With ?waits=1 the start up files report what they waited on; for a statement typed below, the plan's Buffers and I/O Timings lines carry the same information. auto_explain: on/off flips auto_explain.log_min_duration between the bed's threshold and -1 — for a quiet panel, or to measure without the plan logging in the numbers.
?bluebox=1 loads the Bluebox sample schema on start up and &jobs=1 starts its schedule. PGlite has no pg_cron, so that schedule is a timer in this page — the jobs and every execution live in the job schema, queryable as job.status and job.recent_runs.
